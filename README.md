# Музейный каталог

Консольное приложение для учёта музейных экспонатов и управления
коллекцией.

## Возможности

- просмотр всех экспонатов;
- добавление нового экспоната;
- поиск экспонатов по автору;
- фильтрация экспонатов по состоянию;
- сортировка по стоимости;
- подсчёт общей стоимости коллекции;
- сохранение данных в JSON-файл.

## Структура проекта

- `main.py` — точка входа, меню приложения;
- `exhibits.py` — логика работы с экспонатами;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/exhibits.json` — файл данных;
- `tests/test_exhibits.py` — автоматизированные тесты.

## Требования

- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

## Запуск тестов

    pytest

## Проверка качества кода

    flake8 .

# Музейный каталог

## Назначение

Музейный каталог — приложение для учёта экспонатов музея. Консольная версия (ПР3) дополнена веб-интерфейсом на Django (ПР5).

Приложение позволяет:

* просматривать список экспонатов в браузере;
* просматривать информацию о конкретном экспонате;
* просматривать авторов и их работы;
* просматривать коллекции и входящие в них экспонаты;
* видеть состояние экспоната, его доступность и статус;
* рассчитывать возраст экспоната;
* добавлять авторов, коллекции и экспонаты через консольное приложение;
* искать экспонаты по автору, фильтровать по состоянию и коллекции;
* сортировать экспонаты по стоимости и считать общую стоимость.

## Предметная область

Основные объекты:

* **Author** — автор (имя, фамилия);
* **Collection** — коллекция (название, описание);
* **Condition** — состояние экспоната (отличное, хорошее, удовлетворительное, плохое; флаги «требует реставрации», «требует проверки»);
* **Exhibit** — экспонат (название, автор, коллекция, состояние, год создания, стоимость, доступность для выставки).

Экспонат связан с автором, коллекцией и состоянием. Состояние определяет статус экспоната (готов к выставке, требует проверки, требует реставрации, временно недоступен).

## Используемые технологии

* Python
* Django — веб-фреймворк
* PostgreSQL 16 — база данных
* HTML — разметка страниц
* CSS и Bootstrap 5.3 (CDN) — оформление
* pytest — автоматизированные тесты
* flake8 — проверка качества кода
* Docker Compose — запуск приложения и БД

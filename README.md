# Система учета музейных экспонатов

## Назначение

Приложение предназначено для учета музейных экспонатов, информации об их авторах, коллекциях и текущем состоянии. Система должна упростить хранение, просмотр и дальнейшее управление информацией об экспонатах музея.

## Предметная область

Предметная область включает учет музейных экспонатов и связанных с ними данных. Для каждого экспоната необходимо хранить его название, автора, принадлежность к коллекции, год создания, стоимость и текущее состояние.

## Основные сущности

* Экспонат — объект музейного учета.
* Коллекция — группа экспонатов, объединенных по определенному признаку.
* Автор — создатель экспоната.
* Состояние — текущее физическое состояние экспоната.

## Основные функции

* регистрация информации о музейном экспонате;
* определение возможности экспонирования экспоната в зависимости от его состояния;
* расчет возраста экспоната по году создания;
* просмотр основной информации об экспонате.
